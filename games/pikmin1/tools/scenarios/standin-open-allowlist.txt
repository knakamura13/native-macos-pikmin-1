# Files a stand-in scenario run may fail to open (#68). One path per line,
# relative to assets/; a line ending in '/' covers every path under it.
# run_standin_scenario.cmake fails a run on any other "FAILED to open" line.
# Each group says why the game tolerates the absence and why no v1 scenario
# needs the file. Collected from boot_smoke, throw_release and day30_clock at
# 30 and 60 ticks per second on macOS, 2026-10-27.

# No texture (.bti, .txe), .bun or .anm bundle and no AnimMgr table is
# allowlisted: the generator writes every one the disc boot opens (#67, #66 and
# standin_objects.cpp). standin-texture-experiments.md records what happens when
# a texture or bundle is missing or malformed.

# Sandbox generator files. Every .gen read is guarded (gameCoreSection.cpp
# initStage): the day file prints NOT FOUND, init and plants are skipped.
# Scenarios spawn their own Pikmin (#61), so only default.gen is written.
dataDir/stages/sandbox/0.gen
dataDir/stages/sandbox/1.gen
dataDir/stages/sandbox/init.gen
dataDir/stages/sandbox/plants.gen
# The object stage (standin_objects_stage.h) writes only default.gen too.
dataDir/stages/sandbox_objects/0.gen
dataDir/stages/sandbox_objects/1.gen
dataDir/stages/sandbox_objects/init.gen
dataDir/stages/sandbox_objects/plants.gen
# The every-object stage (standin_all_objects_stage.h) writes only default.gen too.
dataDir/stages/sandbox_all_objects/0.gen
dataDir/stages/sandbox_all_objects/1.gen
dataDir/stages/sandbox_all_objects/init.gen
dataDir/stages/sandbox_all_objects/plants.gen

# Parameter files CoreNode::load skips silently when missing (node.cpp); every
# value keeps its code default. key.bin: the throw key stays A, which
# throw_release asserts. demo, sound: no demo flags or sound constants are read
# by a v1 scenario.
dataDir/parms/demo.bin
dataDir/parms/sound.bin
dataDir/parms/key.bin
dataDir/camera/camepara.bin

# The disc's naka1 table names three animations its bundle lacks, so the game
# opens loose .dck files that do not exist there either (FAILED in the boot
# manifest). The stand-in naka1 bundle holds all five entries, so these open
# nothing; the line stays so a future bundle change cannot turn them into
# failures unnoticed.
dataDir/objects/ufoparts/mnaka1/

# Native JAudio builds only (PIKMIN_NATIVE_JAUDIO=ON; the OFF facade opens it
# with fopen, not DVDOpen): Bank_Setup (bankloader.c) returns when the bank is
# missing, so no wave group exists and every WaveScene_* call is a no-op. The
# stand-in sequences play no notes, so nothing needs a bank (standin-audio.md).
dataDir/SndData/Banks/pikibank.bx

# Ghost replay record: gameCoreSection.cpp opens it and checks for null.
dataDir/ghost/record.gst

# No cinema is allowlisted for the boot: the generator writes demo60 (the
# post-extinction movie the sandbox plays on Day 1) and every cinema the disc
# boot opens (standin-cinema.md).
# captain_death: a missing .cin is a zero-length movie (System::openFile returns
# null, CinematicPlayer::loadCin returns early; coverage/README.md). The chain
# needs none of their keys. The results backdrop demo36 is written, because the
# results screen stays up only while that movie is active.
dataDir/cinemas/demo52.cin
dataDir/cinemas/demo32.cin
dataDir/cinemas/demo56.cin
dataDir/cinemas/demo84.cin
# onion_unlock, onion_unlock_whistle: the first-pluck movies (DEMOFLAG_Pluck*Pikmin,
# movies 9-11) play as zero-length movies, as above. The scenarios assert the
# state PikiNukareState::cleanup and pcUnlockColourFromAutoPluck write, which the
# movies do not carry; the text windows their keys would open are not covered.
dataDir/cinemas/demo09.cin
dataDir/cinemas/demo10.cin
dataDir/cinemas/demo11.cin

# captain_death: the three textures EffectMgr2D registers that effects.bun does
# not hold (the file-select and results screens build the 2D effect manager when
# ogScrFileSelectMgr is constructed). loadTexture returns null for them; the
# stand-in particles (effects.bun, standinPcr2dNames) are inert and never draw.
dataDir/effects/tex/waku.bti
dataDir/effects/tex/waku02.bti
dataDir/effects/tex/waku03.bti
