# Files a stand-in scenario run may fail to open (#68). One path per line,
# relative to assets/; a line ending in '/' covers every path under it.
# run_standin_scenario.cmake fails a run on any other "FAILED to open" line.
# Each group says why the game tolerates the absence and why no v1 scenario
# needs the file. Collected from boot_smoke, throw_release and day30_clock at
# 30 and 60 ticks per second on macOS, 2026-10-27.

# No texture (.bti, .txe), .bun or .anm bundle and no AnimMgr table is
# allowlisted: the generator writes every one the disc boot opens (#67, #66 and
# standin_objects.cpp). standin-texture-experiments.md records what happens when
# a texture or bundle is missing or malformed.

# Sandbox generator files. Every .gen read is guarded (gameCoreSection.cpp
# initStage): the day file prints NOT FOUND, init and plants are skipped.
# Scenarios spawn their own Pikmin (#61), so only default.gen is written.
dataDir/stages/sandbox/0.gen
dataDir/stages/sandbox/1.gen
dataDir/stages/sandbox/init.gen
dataDir/stages/sandbox/plants.gen

# Parameter files CoreNode::load skips silently when missing (node.cpp); every
# value keeps its code default. key.bin: the throw key stays A, which
# throw_release asserts. demo, sound: no demo flags or sound constants are read
# by a v1 scenario. tekipara: the enemy parameters, read per enemy type.
dataDir/parms/demo.bin
dataDir/parms/sound.bin
dataDir/parms/key.bin
dataDir/camera/camepara.bin
dataDir/tekipara/

# The disc's naka1 table names three animations its bundle lacks, so the game
# opens loose .dck files that do not exist there either (FAILED in the boot
# manifest). The stand-in naka1 bundle holds all five entries, so these open
# nothing; the line stays so a future bundle change cannot turn them into
# failures unnoticed.
dataDir/objects/ufoparts/mnaka1/

# Ghost replay record: gameCoreSection.cpp opens it and checks for null.
dataDir/ghost/record.gst

# The post-extinction explanation movie (DEMOID_Unk60Cat; on disc the Forest
# of Hope plays demo61). finalSetup triggers it because the squad is spawned
# after the stage is ready. With no cinema stand-in, MoviePlayer finds no file
# and the movie ends at once; the runner's intro gate waits for it either way.
dataDir/cinemas/demo60.cin
